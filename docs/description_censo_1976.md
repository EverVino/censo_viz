# Detalles del archivo del censo

Los departamento de Bolivia tiene asignado un codigo que facilita su identificacion.

```
1 Chuquisaca
2 La Paz
3 Cochabamba
4 Oruro
5 Potosí
6 Tarija
7 Santa Cruz
8 Beni
9 Pando
```

En la columna p03 se identifica a clasifica a la poblacion como hombre y mujer.

```
1 Hombre
2 Mujer
```

Para consultar datos que no son descargables de los censos como el caso de los datos del censo de 2001 
(No se encuentra en su sitio web y el que se encuentra es incompleto) se puede usar la siguiente plataforma para
obtener datos https://redatam.org/es/procesar-en-linea/latam/bol
